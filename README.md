# 🎯 Mi Agenda

Agenda de disciplina, fe y enfoque para añadir objetivos **tocando botones**, casi sin escribir. Estilo oscuro y sobrio con versículo bíblico diario.

## Cómo se usa

1. Abre `index.html` en el navegador (móvil u ordenador).
2. Toca **＋ Añadir objetivo** → elige una categoría (💪 Deporte, 📚 Estudio, ❤️ Salud…) → elige el objetivo.
3. Elige con botones **cuándo** (mañana / tarde / noche), **si se repite** (solo ese día, todos los días, L-V, fin de semana o los días que quieras) y **cuántas veces** (por ejemplo 💧 8 vasos de agua).
4. Toca un objetivo para marcarlo como hecho ✓ (o sumar +1 si tiene varias veces).
5. Toca **⋯** para saltarlo ese día o borrarlo.

Extras: semana deslizable, anillo de progreso, racha de días perfectos 🔥, confeti al completar el día y modo oscuro automático.

Los datos se guardan en el propio navegador (`localStorage`), no hace falta cuenta ni internet.
En el móvil puedes usar "Añadir a pantalla de inicio" para tenerla como una app.
